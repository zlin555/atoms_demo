# Atoms Agent Demo Frontend

React/Vite frontend for the Atoms-style agent builder demo.

## Local run

```bash
npm install
npm run dev
```

Create `.env.local`:

```bash
VITE_API_BASE_URL=http://localhost:7860
```

## Vercel deployment

Deploy this folder as the Vercel project root.

Set:

```bash
VITE_API_BASE_URL=https://your-huggingface-space.hf.space
```
